## What you can do

- **Run privately.** Jobmatcha is a self-hosted Go service with a React dashboard and a SQLite data volume.
- **Find the signal.** It scans the seeded supported-company set, filters roles using your preferences, and explains each match.
- **Operate confidently.** Use the deployment, backup, upgrade, and troubleshooting guides when you take it beyond your laptop.
