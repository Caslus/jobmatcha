---
title: Build your first shortlist
description: Complete onboarding and run your first scan.
---

1. **Set your target.** Add include keywords, excluded terms, locations, work types, and a freshness window. You can change all of them later from the dashboard.
2. **Review the companies.** Start with the seeded company set, then open **Companies** to discover career boards from a careers page or add, edit, enable, and remove boards yourself. Greenhouse and Workable are the supported scanners.
3. **Choose a schedule.** Enable scheduled scanning with a five-field cron expression and an IANA timezone, or leave it disabled and scan on demand. Settings validates those values; onboarding currently stores them without validation, so correct an invalid value in Settings.
4. **Review the signal.** Open the ranked feed, inspect the match explanation, mark promising roles, and use the original posting when you are ready to apply.

Resume parsing is optional. If you configure OpenRouter, you can upload a PDF, Markdown, or text resume to suggest profile data and preferences. You can instead enter those details manually.

See [relevance preferences](/guides/relevance/) for the exact filtering and ranking behavior.
