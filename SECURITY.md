# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, pull requests, or social media.

Use [GitHub private vulnerability reporting](https://github.com/Caslus/jobmatcha/security/advisories/new) instead. Include a clear description, affected version or commit, reproduction steps, impact, and any suggested mitigation. Project maintainers will coordinate disclosure and a fix privately.

This reporting path requires GitHub private vulnerability reporting to be enabled in the repository's Security settings.

## Scope

Security reports are welcome for the Jobmatcha application, container build, GitHub Actions workflows, and documentation-controlled deployment guidance. Reports involving third-party providers should include enough information to distinguish an upstream issue from Jobmatcha behavior.
